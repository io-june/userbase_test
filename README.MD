## Тестовое задание на обработку табличных данных из базы данных

Работает с удаленной БД MS SQL Server, локальными MS Access, SQLite.

Пока строка для подключения смотрится неказисто - не хватило времени на реализацию полноценной авторизации:

```
Server=<домен>,<порт>;Database=<название_бд>;User Id=<юзер>;Password=<пароль>
```

В файл-пикере можно выбрать тип БД при создании/открытии - Access или SQLite.
